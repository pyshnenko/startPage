# Центральный сайт

Персональная стартовая страница с навигацией по проектам, профилем автора и дополнительными интерактивными возможностями. Интерфейс поддерживает светлую и тёмную темы, адаптивную компоновку и стеклянные визуальные эффекты.

![Демонстрация интерфейса](public/demoFiles/startPage_360.gif)

## Возможности

- **Главная страница** с навигацией и ссылками на проекты.
- **Minio** и другие связанные разделы сайта.
- **Блокнот и облако** для перехода к соответствующим сервисам.
- **AR-проекты** — просмотр проектов дополненной реальности с использованием маркеров.
- **Старые проекты** — доступ к предыдущим работам.
- **Профиль и информация об авторе.**
- **Настройки интерфейса:** выбор темы и индикатора загрузки, переключатель отображения логотипа.
- **Адаптивное меню** и обновлённый интерфейс с эффектами glassmorphism.
- **Socket.IO** для клиентского взаимодействия с сервером и получения событий в реальном времени.

> Доступность отдельных разделов и функций зависит от конфигурации серверов и связанных сервисов.

## Технологии

- [React 19](https://react.dev/) и React DOM
- [TypeScript 5.9](https://www.typescriptlang.org/)
- [Vite 7](https://vite.dev/) для локальной разработки и сборки
- [Material UI 7](https://mui.com/) и Emotion
- [Axios](https://axios-http.com/) для HTTP-запросов
- [Socket.IO Client](https://socket.io/) для событий в реальном времени
- [Vitest](https://vitest.dev/) и jsdom для тестов

## Требования

- Node.js **20.19+** или **22.12+**
- npm
- Доступ к npm registry для установки зависимостей

## Установка и запуск

Установи зависимости:

```bash
npm install
```

Запусти сервер разработки:

```bash
npm run dev
```

Vite выведет локальный адрес в терминал. Открой его в браузере.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить Vite в режиме разработки |
| `npm start` | Альтернативная команда запуска Vite |
| `npm run build` | Проверить TypeScript и собрать production-версию |
| `npm run preview` | Локально посмотреть production-сборку |
| `npm test` | Запустить тесты один раз через Vitest |
| `npm run test:watch` | Запустить Vitest в режиме наблюдения |

Production-сборка сохраняется в каталоге `build/`.

## Структура проекта

```text
.
├── public/                 # Статические файлы, доступные без импорта
├── src/

├── index.html              # HTML-шаблон Vite
├── vite.config.ts          # Конфигурация Vite
├── vitest.config.ts        # Конфигурация тестов
├── tsconfig.json           # Конфигурация TypeScript
└── package.json            # Зависимости и команды проекта
```

## Тестирование и подготовка к публикации

Перед публикацией выполни:

```bash
npm test
npm run build
npm run preview
```

Проверь основные сценарии в браузере:

- вход и регистрация;
- восстановление пользовательской сессии;
- переключение светлой и тёмной темы;
- настройки и сохранение предпочтений;
- переходы по разделам и работа мобильного меню;
- AR-страница и загрузка изображений;
- подключение к API и получение событий Socket.IO.

## Серверная конфигурация

При обновлении интерфейса важно сохранять совместимость с существующим API. Адреса серверов, способ авторизации, ключи локального хранилища и названия событий Socket.IO должны соответствовать текущей серверной конфигурации. Перед изменением этих контрактов проверь связанные серверные сервисы.

Не помещай секреты, пароли или приватные ключи в клиентский код: всё, что включено во frontend-сборку, доступно пользователю браузера.

## Примечания по миграции

Проект переведён с Create React App на Vite и обновлён до React 19, TypeScript 5.9 и Material UI 7. Дополнительные детали и ограничения миграции описаны в [`MIGRATION_VITE.md`](MIGRATION_VITE.md), а сведения о визуальном обновлении — в [`MODERNIZATION.md`](MODERNIZATION.md).

**Статус проверки:** в среде подготовки не удалось установить зависимости и выполнить production-сборку. После установки пакетов локально обязательно запусти `npm run build` и `npm test`; не считай сборку проверенной до успешного выполнения этих команд.
