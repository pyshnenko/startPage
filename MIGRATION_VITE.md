# Миграция на Vite, React 19 и Material UI 7

## Что изменено
- Create React App / `react-scripts` заменён на Vite 7 и `@vitejs/plugin-react`.
- React и React DOM обновлены до 19.x; типы React — до 19.x.
- Material UI и иконки обновлены до 7.x; Emotion остаётся движком стилей.
- TypeScript обновлён до 5.9 с `moduleResolution: Bundler` и JSX transform `react-jsx`.
- Добавлен Vitest + jsdom для существующих тестов.
- Входной `index.html` перенесён в корень, CRA-маркеры `%PUBLIC_URL%` удалены.
- Сборка по-прежнему выводится в `build/`, чтобы снизить риск нарушения текущего размещения сайта.
- Удалена зависимость `react-swipeable-views`, давно не обновлявшаяся для React 19; в старой странице заменена локальной каруселью с автопрокруткой и свайпом.
- API-клиент, URL серверов, авторизация и Socket.IO-события намеренно не менялись.

## Запуск
Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Проверки перед публикацией:

```bash
npm run build
npm test
```

## Важные замечания
- `package-lock.json` удалён, потому что он фиксировал CRA-зависимости. `npm install` создаст новый lock-файл для обновлённого стека. После успешной установки добавьте его в систему контроля версий.
- В среде подготовки не было доступа к npm registry, поэтому установка пакетов и production build не запускались. Возможны несовместимости типов или runtime, которые нужно исправить по результатам `npm run build`; особенно проверьте страницы регистрации, настроек и старую мобильную карусель.
- В проекте намеренно оставлены исходные API URL и логика серверного взаимодействия.
